# Ciencia COOLinaria® — sitio web

Este paquete está listo para GitHub Pages.

## Publicación
1. Crea un repositorio en GitHub.
2. Sube `index.html` y la carpeta `assets/` manteniendo exactamente la estructura.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, rama `main`, carpeta `/root`.
4. GitHub publicará el sitio estático sin costo.

## Edición
- `index.html`: textos, enlaces y estructura.
- `assets/marca/`: identidad visual.
- `assets/equipo/`: fotografías del equipo.
- `assets/instituciones/`: logos institucionales.
- `assets/galeria/`: fotografías de actividades.

Las fotos de la galería fueron optimizadas para web para reducir el peso del repositorio.
